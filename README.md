# 📈 StockMarket Buddy

StockBuddy is a market-data application that provides real-time financial market information across major global and MENA markets.

The project is designed to collect, normalize, and expose stock and index data through a simple API, making it easy for frontend applications, dashboards, and financial tools to consume market information.

---

## ✨ Features

- 📊 Real-time market data
- 🇺🇸 US stocks and major indices
- 🇸🇦 Saudi Arabian stocks
- 🇦🇪 UAE markets
- 🇶🇦 Qatar markets
- 🇰🇼 Kuwait markets
- 🇪🇬 Egyptian markets
- 🇧🇭 Bahrain market support
- 🇴🇲 Oman market support
- 🇯🇴 Jordan market support
- 🇲🇦 Morocco market support
- 📈 Stock and index prices
- 💹 Price changes and percentage changes
- 📉 Daily high and low prices
- 🔄 Open prices
- 📊 Trading volume
- ⚡ API caching
- 🛡️ Graceful handling of unavailable market data
